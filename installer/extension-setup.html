Connect Chrome

One manual step keeps the extension yours.

  1. Open chrome://extensions and turn on Developer mode.
  2. Choose Load unpacked, then select the extension folder beside this page.
  3. Copy the 32-letter extension ID shown by Chrome.
  4. Open PowerShell in this folder and run:.\tools\register-native-host.ps1 -InstallRoot . -ExtensionId YOUR_EXTENSION_ID
  5. Restart OFEnhancer. Its status should change to Connected.

Chrome will mention debugger access. OFEnhancer uses it only to attach a local file to the exact upload control, then detaches. This setup does not post anything.
