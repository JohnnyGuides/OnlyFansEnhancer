Connect Chrome

Prepare the integration, then finish the required steps in Chrome.

  1. Open OFEnhancer and select the Chrome connection button in the sidebar, or choose Connect Chrome from the Start menu.
  2. For a fresh installation, choose Prepare integration. OFEnhancer validates its installed package and registers its own current-user native bridge. This does not load the extension.
  3. Choose Open Chrome extensions. If necessary, paste chrome://extensions into Chrome's address bar.
  4. Enable Developer mode, choose Load unpacked, and select the exact extension-keyed folder displayed by OFEnhancer.
  5. Leave OFEnhancer open. Its status changes only after fresh matching extension messages arrive; no desktop restart or copied extension ID is needed.

Already using the extension? Preserve its existing load folder, ID, settings and upload checkpoints. Open Chrome and check again first; reload the existing extension after an update. Do not remove it or load the new keyed folder to repair a legacy installation. OFEnhancer stops with specific guidance when legacy installation evidence is insufficient.

Chrome will mention debugger access. OFEnhancer uses it only to attach a local file to the exact upload control, then detaches. This setup does not post anything.
