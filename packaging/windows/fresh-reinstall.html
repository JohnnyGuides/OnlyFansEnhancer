Remove the previous Chrome installation

Do not click Reload. Reload is an update, not removal, and cannot complete a Fresh reinstall.

  1. Open chrome://extensions in this same Chrome profile and enable Developer mode.
  2. Choose Load unpacked and select this temporary verifier folder:
  3. Return to Setup and click OK. OFEnhancer will request supported self-removal. If Chrome refuses or the old runtime does not support it, remove extension ID with its Remove button.
  4. Leave this Chrome profile open. The temporary verifier includes disabled extensions, observes the uninstall event, reports only the target identity, and removes itself after confirmation.

Setup will not delete desktop data or install new files until this gate succeeds.
