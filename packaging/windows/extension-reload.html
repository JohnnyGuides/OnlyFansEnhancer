Update your Chrome extension

This keeps the existing extension and its settings.

  1. Open Chrome extensions

    Copy this address and paste it into Chrome.

    chrome://extensions

  2. Reload Creator Workflow Toolkit

    Click Reload on its card. Check that the version is 0.20.32.

  3. Check connection

    Check connection in OFEnhancer

Need a clean installation instead?

Choose Fresh reset in OFEnhancer. It removes or blocks the previous extension and clears extension-owned state; a reload cannot complete it. Your desktop catalogue, Google connection and history stay intact.

Existing load folder

For a normal update, keep the same extension ID and load folder. Do not remove the extension unless you choose Fresh reset.
