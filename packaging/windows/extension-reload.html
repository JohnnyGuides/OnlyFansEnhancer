Reload the Chrome extension

After updating, reload your existing extension to use the new files.

  1. Open the address below in Chrome.
  2. Find Creator Workflow Toolkit.
  3. Click Reload, then check that it shows version 0.20.19.

Keep the same extension ID and load folder. Do not remove the extension or load a different folder: your Chrome settings and upload checkpoints belong to the existing identity. OFEnhancer checks the live connection automatically; the separate X recorder host is not checked by that connection.
